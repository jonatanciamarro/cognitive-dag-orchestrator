## ⚡ Modelo de Crescimento

### Fórmula de Tráfego

```
visitas/mês = Σ(artigos_coorte × visitas_pico × rampa_SEO × decay)
```

Onde:
- **Rampa SEO:** 3-6 meses para atingir pico de tráfego
- **Decay:** 2% de queda/mês após o pico (conteúdo evergreen)
- **Compounding:** Cada mês adiciona uma nova coorte de artigos

### Fórmula de Receita por Fonte

```
receita_fonte = visitas_fonte × CTR × conversão × ticket × comissão
```

Para **assinaturas** (recorrência):
```
receita_mês = membros_ativos × R$ 27
membros_ativos = Σ(novos_membros_cada_mês)
novos_membros/mês = visitas_mês × 0,3%
```
