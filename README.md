## 🚀 Quick Start

```bash
# 1. Clone e configure
cp .env.example .env
# Preencha suas chaves no .env

# 2. Configure afiliados
# Veja docs/COMO_OBTER_LINKS_AFILIADO.md

# 3. Execute produção
python scripts/run_all_niches.py

# 4. Veja o dashboard
streamlit run dashboard/app.py

# 5. Gerencie links
python scripts/manage_links.py stats
```
