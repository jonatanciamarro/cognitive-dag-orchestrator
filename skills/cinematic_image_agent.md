# Cinematic Image Agent

## Propósito

Gerar imagens com qualidade cinematográfica para todas as plataformas usando ferramentas gratuitas (Pillow).

## Responsabilidades

- Gerar imagens featured para blog (1200x630)
- Criar thumbnails para YouTube (1280x720)
- Produzir pins para Pinterest (1000x1500)
- Gerar posts para Instagram (1080x1080)
- Criar cards para redes sociais
- Aplicar color grading, iluminação e efeitos

## Inputs

- Tópico do conteúdo
- Plataforma alvo
- Guia de estilo visual
- Paleta de cores

## Outputs

- Imagem gerada em alta resolução
- Metadados da imagem (formato, dimensões)
- Caminho do arquivo salvo

## Requer

- Pillow (PIL) instalado (`pip install Pillow`)

## Regras

- Imagens devem ter proporção correta para cada plataforma
- Color grading deve ser consistente com a marca
- Texto em imagens deve ser legível em miniaturas
