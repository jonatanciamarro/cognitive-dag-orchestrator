# SEOResearchAgent

## Função
Pesquisa palavras-chave e tópicos para conteúdo orgânico.

## Entrada
- Nicho (do campaign context)
- Canais configurados

## Saída
- Lista de keywords com volume e dificuldade
- Oportunidades de baixa concorrência
- Análise por canal

## Regras
- Priorizar keywords com difficulty < 0.50
- Preferir intent "informational" para atrair tráfego
- Keywords "commercial" para páginas de afiliado
- Ignorar termos restritos

## Observações
- Atualmente usa dados simulados
- Em produção: integrar com Ahrefs API ou Semrush API
