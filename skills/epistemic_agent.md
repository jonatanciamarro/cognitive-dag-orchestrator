# Epistemic Agent

## Propósito

Auto-questionamento epistêmico de terceira ordem. O sistema questiona o que sabe, o que não sabe, e o que não sabe que não sabe.

## Responsabilidades

- Mapear fatos verificados, suposições, desconhecidos e pontos cegos
- Gerar hipóteses alternativas para fenômenos observados
- Questionar suposições fundamentais do sistema
- Escanear por "unknown unknowns" (riscos desconhecidos)
- Produzir relatório de saúde epistêmica

## Inputs

- Nicho da campanha
- Resultados de ciclos anteriores (via memória semântica)
- Crenças atuais do sistema

## Outputs

- Mapa de conhecimento (knowledge_map)
- Pontos cegos identificados (blind_spots)
- Suposições desafiadas (assumptions_challenged)
- Hipóteses alternativas (alternative_hypotheses)
- Relatório epistêmico (epistemic_report)

## Regras

- Nunca confundir suposição com fato verificado
- Toda hipótese deve ter nível de confiança explícito
- Pontos cegos de alta severidade exigem experimentos recomendados
- O relatório deve incluir ações concretas para reduzir incerteza
