# 📋 Growth Hacking Checklist — Campanha de Afiliados Orgânica

> Checklist semanal para maximizar resultados de tráfego orgânico.

## ☐ SEO Foundation
- [ ] Pesquisa de keywords com baixa dificuldade (<40) e intenção comercial
- [ ] Página piloto criada para o tema central
- [ ] Artigos cluster linkando para a piloto
- [ ] Internal linking entre todos os artigos (mín. 3 links/artigo)
- [ ] Meta descriptions únicas para cada página
- [ ] URLs amigáveis e descritivas
- [ ] Imagens com alt text rico em keywords
- [ ] Sitemap.xml atualizado e submetido ao Google

## ☐ Featured Snippets
- [ ] Seção de FAQ em cada artigo (3-5 perguntas)
- [ ] FAQ Schema (JSON-LD) implementado
- [ ] Respostas diretas de 40-50 palavras
- [ ] Formato lista/tabela para queries comparativas
- [ ] Monitorar posição zero no Search Console

## ☐ Content Upgrades (Email List)
- [ ] Upgrade específico para o artigo mais acessado
- [ ] CTA no meio do artigo (+ meio do artigo)
- [ ] CTA no final do artigo
- [ ] Pop-up de saída com lead magnet
- [ ] Entrega automática por email
- [ ] Taxa de conversão > 5%?

## ☐ Cross-Channel
- [ ] Artigo do blog → YouTube script
- [ ] YouTube vídeo → Pinterest pins
- [ ] Blog post → Twitter thread
- [ ] Twitter thread → Newsletter
- [ ] Newsletter → WhatsApp broadcast
- [ ] Links entre todas as versões do conteúdo

## ☐ Share Triggers
- [ ] Citações destacadas com Click to Tweet
- [ ] Infográfico com embed code
- [ ] Checklist imprimível
- [ ] Botões de compartilhamento visíveis
- [ ] Contador de compartilhamentos

## ☐ Backlinks
- [ ] Links quebrados identificados no nicho
- [ ] HARO/SourceBottle responses enviadas
- [ ] Guest posts propostos para blogs do nicho
- [ ] Comentários de valor em blogs autoritativos
- [ ] Menções não-linkadas identificadas

## ☐ SEO Técnico
- [ ] Core Web Vitals OK (LCP < 2.5s, FID < 100ms, CLS < 0.1)
- [ ] Mobile-friendly test passed
- [ ] HTTPS ativo
- [ ] Redirects configurados (301)
- [ ] Páginas órfãs identificadas e linkadas
- [ ] Conteúdo duplicado canônico

## ☐ Email Marketing
- [ ] Sequência de boas-vindas (3-5 emails)
- [ ] Lead magnets em todos os artigos
- [ ] Segmentação por interesse
- [ ] Taxa de abertura > 20%?
- [ ] Taxa de clique > 3%?
- [ ] Link de descadastro em todos os emails

## ☐ Evergreen Refresh
- [ ] Artigos com tráfego em declínio identificados
- [ ] Dados e estatísticas atualizados
- [ ] Novas seções adicionadas
- [ ] Ano atualizado no título
- [ ] Republicado com data atualizada

## ☐ Analytics
- [ ] Google Analytics 4 configurado
- [ ] Google Search Console conectado
- [ ] Metas de conversão configuradas
- [ ] Event tracking de cliques em links de afiliado
- [ ] Dashboard de KPIs semanal
- [ ] Acompanhamento de rankings de keywords
