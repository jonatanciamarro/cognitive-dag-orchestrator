# Content Research Agent

## Propósito

Pesquisar palavras-chave, intenção de busca, concorrência e gaps de conteúdo para orientar a produção editorial.

## Responsabilidades

- Pesquisar keywords com volume e dificuldade
- Classificar intenção de busca (informacional, comercial, transacional)
- Analisar concorrência para cada keyword
- Identificar content gaps e oportunidades
- Sugerir tipo de conteúdo ideal para cada oportunidade

## Inputs

- Nicho da campanha
- Base de dados de keywords simulada

## Outputs

- Keywords com volume, dificuldade, intenção e CPC
- Análise competitiva por keyword
- Oportunidades priorizadas
- Estratégia de conteúdo recomendada

## Regras

- Dados simulados — substituir por API real em produção
- Priorizar keywords com alto volume e baixa dificuldade
- Balancear conteúdo informacional e comercial
